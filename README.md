# ShopEasy

ShopEasy is a modern, responsive e-commerce website built using only HTML, CSS, and Vanilla JavaScript. It uses `localStorage` for cart and wishlist management.

## Features
- Responsive design for all devices
- Product catalog with search, sort, and filter functionality
- Shopping cart with automatic calculations
- Wishlist feature
- Toast notifications
- Simulated checkout process

## Setup Instructions
1. Clone or download the repository.
2. Open `index.html` in your browser.
3. No server or backend setup is required!
